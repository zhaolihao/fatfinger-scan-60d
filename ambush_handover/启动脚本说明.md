# 启动脚本说明

## 重要：767币脚本（默认使用）

**启动命令：**
```bash
bash start_767.sh
```

**脚本内容：**
- 币对文件：`planR_all.json`（767个币）
- 参数：
  - `--mode react`：响应式模式
  - `--notional 10`：每笔 10U
  - `--depth 0.08`：阈值 8%
  - `--reb-anchor`：锚价回归
  - `--reb 0.06`：回归 6%
  - `--anchor-sec 1`：锚价每秒刷新
  - `--anchor-jump-gate 0`：关闭跳变闸门

**日志文件：**
- `logs/ambush_basket_YYYYMMDD_HHMMSS.log`

**历史记录：**
