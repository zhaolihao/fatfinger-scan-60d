## 一句话结论
**回测触发判定不是「(close-open)/open 涨幅」, 而是「high ≥ base × 1.10」**。
- 这一秒 high=0.021233, base=**0.019111** (不是 05:56:10 close, 也不是 open)
- 0.021233 / 0.019111 - 1 = **+11.09%** ← 早就穿墙 10%
- close=0.020670 vs base=0.019111 = +8.16% (这是 close-base, 不是 close-open)
- 用户看到的"涨幅 9.15%" = high-vs-open, 这是错的比较对象

## 锚价机制 (1s 跟随)
**base 不是简单的"上一秒收盘", 而是「最近一次跟随重挂时的 close」**, 重挂条件 `mv = |c-base|/base ≥ 2%`:

| 时间 | close | base 变化 |
|---|---|---|
| 05:56:01 | 0.019884 | 0.007936 (初始 bars[0][4]) |
| 05:56:02 | 0.020097 | 0.019884 (mv≈4.4%, 重挂到本秒 close) |
| 05:56:05 | **0.019111** | 0.019884 (mv≈3.88%, 重挂到本秒 close) |
| 05:56:06~10 | ... | **0.019111 锁住 5 秒** (mv 全部 < 2%) |
| 05:56:11 | 0.020670 | 仍 0.019111 |

**所以 05:56:11 触发那一刻的 base = 0.019111** (来自 05:56:05 的 close, 中间隔了 5 根 K 线, 但因波动小没重挂)。

## 触发判定 + 成交价
代码 `_four_logic_sim.py:226-237`:
```
for side, px_hit in (('BUY', l), ('SELL', h)):   # SELL 用 high, BUY 用 low
    if side == 'BUY' and px_hit > stt['trig']: continue
    if side == 'SELL' and px_hit < stt['trig']: continue   # 触发: high ≥ trig
    entry = min(stt['trig'], c) if side == 'BUY' else max(stt['trig'], c)   # entry = max(trig, c) for SELL
```

05:56:11 计算:
- trig = 0.019111 × 1.10 = **0.0210221**
- high = 0.021233 ≥ 0.0210221 → SELL 触发 ✓
- entry = max(0.0210221, 0.020670) = **0.0210221** ← 成交明细完全对上 ✓
