## 一、核心代码片段（逐字）

```python
# _four_logic_sim.py L271-285
# --- 跟随重挂(未冻结) ---
if not frozen:
    for side in ('BUY', 'SELL'):
        stt = st[side]
        if s - stt['last'] >= follow_sec:           # 距上次跟随 ≥ 1s
            stt['last'] = s
            mv = abs(c - stt['base']) / stt['base'] # ← mv 用 close 偏离
            if mv >= 0.02:                          # ← 阈值就是 2%
                danger = (c < stt['base']) if side == 'BUY' else (c > stt['base'])
                if gate > 0 and mv >= gate and danger:
                    n_gate += 1
                    continue
                stt['base'] = c                     # 重挂 base = close
                stt['trig'] = c * (1 - depth) if side == 'BUY' else c * (1 + depth)
                n_rep += 1
```

**两处关键判定**：
1. 跟随重挂：`mv = |close - base| / base`，阈值 `0.02`（2%），**只看 close，不看 low/high/振幅**
2. 触发判定（L226-232）：SELL 侧用 `high >= trig`，BUY 侧用 `low <= trig`

## 三、用户 3 个疑惑的具体解答

### 疑惑 A：05:56:08 low=0.01870 距锚价 -2.14%，为何不触发重挂？
**答**：代码里 mv 变量是 `abs(c - base) / base`，用的是 `c`（close）而不是 `low`。
- close = 0.018824
- base = 0.019111
- mv = |0.018824 - 0.019111| / 0.019111 = 0.000287 / 0.019111 = **1.50%** < 2%
- 所以不重挂。

### 疑惑 B：05:56:09 也 low 距 -2.12%，同理 close=0.018995，mv=0.61%，不重挂。

### 疑惑 C：05:56:10 振幅 3.12% 为何不重挂？
**答**：代码 mv 完全不看振幅。振幅=(high-low)/open，是衡量这根K线波动的指标；mv 是 close 相对锚价的偏离，是衡量"市场整体水平有没有偏移"的指标。两者完全不同的概念。

## 四、为什么作者用 close 不用 low/high？— 优化方向分析

### 设计意图猜测
1. **close 是 1s 钟的"成交均价/最后成交价"，代表这 1s 的市场水平**
2. low/high 是这 1s 内出现的极端价位，可能是乌龙指/插针等噪声
3. **用 close 跟随，相当于"过滤掉 1s 内的瞬时噪声，只看趋势**"
4. 1s 周期内如果只是瞬间打到 base×0.95 又收回去（wick），不算趋势偏移

### 这套逻辑的副作用（潜在优化点）
1. **延迟问题**：低点在 05:56:08~09 已经触及 0.01870（距 base -2.15%），但 close 都在 0.0188~0.0190，锚价锁了 5 秒后才被 05:56:11 的暴力插针带动重挂
2. **错失趋势反转**：如果低点真的突破 -2% 但没在 close 上体现，市场可能已经从 base 下方 2% 反弹，但 base 还挂在原位，trig 还按 base×1.10 算
3. **"5 秒锁死"现象**：如果 close 一直围绕 base 浮动但都不超 2%，base 长期不更新，相当于"挂单位置逐渐偏离真实市场"

### 优化方向（4 个候选）

#### 优化 1：用 low/high 当 mv 触发重挂的"加速器"
- 当 low <= base × 0.98 时立即重挂（哪怕 close 没到 2%）
- 优点：更敏感
- 缺点：会被乌龙指/插针误触发，让锚价频繁跳动

#### 优化 2：用"close 偏离 ≥ 1.5%"（降低阈值）
- 把 0.02 改成 0.015
- 优点：减少"5 秒锁死"概率
- 缺点：跟随更频繁，挂单更密，成交可能变差

#### 优化 3：加"时间窗"逻辑
- 如果过去 N 秒累计 close 偏离都接近 2%（比如都 ≥ 1.8%），也重挂
- 优点：适应缓慢趋势
- 缺点：逻辑更复杂，需要调参

#### 优化 4：把 mv 改成 "max(close, high) 距 base 的偏离"（以高者为准）
- 含义：只要 high 或 close 任一距 base 够 2% 就重挂
- 优点：兼顾 close 的稳定性和 high 的趋势敏感性
- 缺点：可能比方案 1 还敏感
